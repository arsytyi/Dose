# Dose

Мобільний застосунок для нагадувань про прийом ліків і БАДів: гнучкий розклад, облік прийомів, запас таблеток і попередження про несумісні добавки.

Перша платформа: Android (64-бітні телефони). Згодом, можливо, iPhone.

- Специфікація: [docs/SPEC.md](docs/SPEC.md)
- Дизайн-система: [design-system/MASTER.md](design-system/MASTER.md)

## Як встановити

1. Відкрийте сторінку [Releases](https://github.com/arsytyi/Dose/releases) і завантажте файл `dose-vX.Y.Z.apk` з останнього випуску.
2. Відкрийте APK на телефоні. Android попросить дозволити встановлення з цього джерела.
3. Під час першого запуску дозвольте сповіщення. У налаштуваннях застосунку можна дозволити точні нагадування.

Нові версії встановлюються поверх старих, дані зберігаються. Застосунок сам раз на день перевіряє, чи є новий випуск (Налаштування → Про застосунок). Для цього репозиторій має бути публічним.

Тестові збірки з гілок: вкладка **Actions** → запуск **CI** → артефакт **dose-apk**.

## Як випустити нову версію

1. Змініть версію в `pubspec.yaml` і `lib/version.dart` (CI перевіряє, що вони збігаються).
2. Після злиття в `main` створіть тег: `git tag v0.7.0 && git push origin v0.7.0`.
3. Workflow **Release** збере підписаний APK і опублікує випуск. Потрібні секрети `BADY_KEYSTORE_BASE64` і `BADY_KEYSTORE_PASSWORD`.

## Резервна копія

Налаштування → Дані → «Зберегти резервну копію» створює JSON-файл з усіма препаратами, розкладами та історією. «Відновити з копії» замінює поточні дані.

## Сумісність і довідник

Усе лежить у [assets/interactions.json](assets/interactions.json):

- `substances`: речовини з варіантами назв (зокрема торговими). У речовини може бути `info`: як приймати, на що зважати, і джерела з посиланнями. Це видно на сторінці препарату (розділ «Довідка») і в Налаштуваннях → «Довідник добавок».
- `rules`: пари «обережно» / «розділяти N год» / «добре разом», кожне з джерелом.
- `products`: готові продукти (назва, бренд, вміст однієї капсули, речовини, форма і колір). Коли вводиш назву препарату, застосунок пропонує їх і сам заповнює форму.

Щоб додати речовину, правило чи продукт, допишіть їх туди; тест перевіряє, що все посилається на відомі речовини і має джерела.

## Розробка

Потрібен Flutter 3.50 (stable).

```sh
flutter pub get
dart run build_runner build   # після змін у lib/data/database.dart
flutter gen-l10n              # після змін у lib/l10n/*.arb
flutter analyze
flutter test
flutter run --flavor github   # або --flavor play
```

Дві збірки (Android product flavors), ідентифікатор `app.dose.reminder`:

- `play` — для Google Play: без доступу до інтернету, оновлення приходять з Play.
  `flutter build appbundle --release --flavor play`
- `github` — APK для GitHub Releases, вміє перевіряти нову версію на GitHub.
  `flutter build apk --release --flavor github --target-platform android-arm64`

Структура:

- `lib/domain/` — логіка розкладу без залежностей від Flutter (`schedule_rule.dart`), групування нагадувань, форматування.
- `lib/data/` — база даних SQLite (drift).
- `lib/services/` — сповіщення, резервні копії, перевірка оновлень.
- `lib/ui/` — екрани і тема (`theme.dart`).
- `lib/l10n/` — переклади: українська (`app_uk.arb`) та англійська (`app_en.arb`).
